## Status Reference
- `evaluated` — Offer evaluated, report generated
- `applied` — Application submitted
- `responded` — Company responded (not interview yet)
- `interview` — Active interview process
- `offer` — Offer received
- `rejected` — Rejected by company
- `discarded` — Discarded by candidate
- `skip` — Doesn't fit, won't apply

## How to Use
1. Each new opportunity gets a sequential number
2. Paste company + role + date + score from evaluation
3. Link to report file: `reports/NNN-company-date.md`
4. Update status as you progress
5. Add notes for context or negotiation points
